# Clausis Apox — Edge POS Client (`clausis_pos_edge`)

The Flutter Edge/POS client for **Clausis Apox**, the transactional and financial core of the
Clausis Global omni-channel retail platform. Runs on desktop and tablet, with zero-lag offline-first
scanning and checkout backed by a local Isar store.

See [ARCHITECTURE.md](./ARCHITECTURE.md) for the folder structure and architectural rules this
project follows.

## Status

Phase 1 (Edge POS Kernel) — project scaffolding only. No application logic has been implemented
yet.

## Getting Started

```bash
flutter pub get
flutter run
```

Requires the Flutter SDK (stable channel) and, for local development, Android/Windows platform
tooling as appropriate for your target device.
